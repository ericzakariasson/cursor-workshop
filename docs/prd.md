# CLI Calculator PRD

## Overview

Command-line calculator application for basic arithmetic operations.

## Features

### Core Functions

- Addition, subtraction, multiplication, division
- Clear command (c)
- Decimal point support
- Negative numbers

### UI/UX

- Text input for numbers and operators
- Single-line command format (e.g. "2 + 3")
- Result displayed after each calculation

## Technical Requirements

- C++ implementation
- Command line interface
- Input validation and parsing
- Floating point precision

## Success Metrics

- Correct calculations
- Error-free operation
- Response time < 100ms

## Timeline

- Development: 1 week
- Testing: 2 days
- Release: 3 days
