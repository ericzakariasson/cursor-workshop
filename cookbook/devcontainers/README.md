# Python Dev Container Example

A minimal example of using VS Code Dev Containers with Python.

## Prerequisites
- Docker Desktop
- VS Code with Dev Containers extension

## Usage
1. Open this folder in VS Code
2. Run "Dev Containers: Reopen in Container"
3. Run `python app.py`
4. Open http://localhost:5000

## Features
- Python 3.12
- Flask web framework
- Black code formatter
